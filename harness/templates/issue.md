# Issue 작성 양식

GitHub에 반영할 때는 [GitHub Issue 게시 양식](<github-issue.md>)을 사용한다.

실제 과제를 준비할 때 복사해 [생성/등록](<../문서 관리.md#create>)을 따른다. 최종 위치에서 링크를 정비하고 실제 GitHub 번호/출처를 확인한다. 가짜 번호·부모 Phase를 넣지 않으며 URL 접근 불가와 번호/대상 불확실성을 구별한다.

[최소 정보/시점](<../../docs/작업 기록 작성 기준.md#minimum>)에 따라 계획·수용 조건은 착수 전에, 사건·검증·종료는 실제 해당 시점에 작성한다. 현재 요약부터 [필요한 근거](<../../docs/문서 관리 기준.md#sources>)만 읽고 기존 기록을 새 양식으로 덮어쓰지 않는다.

## 보유 Task

## 결과와 미해결
