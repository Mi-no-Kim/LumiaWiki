# 별도 계획을 쓰는 Task 본문 양식

<a id="body"></a>

아래 본문을 복사한다. 배정·상태와 링크를 실제 값으로 채운다. 계획을 제시할 때 계획 파일을 만들고 연결한다. 아직 작성하지 않은 계획이나 수행 기록은 미작성·미생성으로 표시한다.

```markdown
# Task <부모 Issue 번호>-<로컬 순번> — <작업 제목>

- 태그: <배정된 활동>

<!-- separate-task-rule:recording
이 본문은 현재 결론·상태·다음 행동을 관리한다.
배정 원문은 적용 전달본에서, 세부 순서와 단계 완료 체크는 별도 계획에서, 실제 검증·복구 근거는 수행 기록에서 관리한다.
착수·재개·단계 전환·수용 전에 Task 공통 절차를 따라 계획·실제 상태·권한을 대조한다.
-->
```
