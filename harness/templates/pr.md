# PR 작성 양식

[PR 작성·검수 기준](<../../docs/details/git/PR과 병합 기준.md#prs>)에 따라 작성한다. 아래 본문 틀을 사용하고, 단계별 작성 범위와 연결 대상은 [단계별 기준](<../../docs/details/git/PR과 병합 기준.md#pr-review>)에서 확인한다. 자리표시자는 실제 내용으로 바꾸고, 기록·근거 링크는 GitHub PR에서 열리는 주소로 맞춘다.

[현재 기록과 당시 근거](<../../docs/문서 참조와 변경 기준.md#references>)를 구별한다. 현재 기록 탐색은 최신 기록으로, 당시 검증 근거는 확인한 커밋의 고정 버전이나 보존된 결과로 연결한다.

## 제목

| 단계                 | 형식                                                    |
| -------------------- | ------------------------------------------------------- |
| task → issue         | `task(<부모 Issue 번호>-<Task 순번>): <Task 결과 요약>` |
| issue → phase / main | `issue(<Issue 번호>): <Issue 결과 요약>`                |
| phase → main         | `phase(<Phase 순번>): <Phase 결과 요약>`                |

## 본문 틀

```markdown
## 결과
<문제·목표와 이번 변경으로 달성한 결과. 긴급 수정이면 긴급한 이유·수정 범위 포함>

## 검증
<수행한 필수 확인과 실제 결과·한계>
<필요한 경우 상세 근거 구역 링크>

## 연결
<담당 작업 기록과 해당하는 부모 기록>
<해당하는 실제 GitHub Issue·sub-issue·milestone 참조>
```

남은 작업·제약·후속 조치가 있을 때만 다음 구역을 `검증` 뒤, `연결` 앞에 추가한다.

```markdown
## 잔여·제약
<남은 내용과 영향·처리 방향 및 근거>
```
