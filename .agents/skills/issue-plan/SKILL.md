# Issue 계획

<!-- inventory-dependencies: ["harness/공용 절차.md", "harness/Issue 공통 절차.md"] -->

1. [공용 절차](<../../../harness/공용 절차.md#operation-commands>)로 대상 Issue와 요청 범위를 확인한다. Issue 본문의 규칙 주석과 [논의·결정](<../../../harness/Issue 공통 절차.md#step-2>)을 읽는다.
2. 기존 질문·결정·배정과 실제 준비를 대조한다. 제안할 배정, 의존 관계, 전체 수용 기준, 남은 결정과 주체·시점을 정리한다. 배정·의존이 복잡하면 Issue 본문에서 세부 계획을 연결한다.
3. 실제 응답이나 명시 위임이 있는 결정만 담당 본문에 확정 근거와 함께 기록한다. 하위 생성과 실행은 해당 단계·권한을 확인할 다음 행동으로 남긴다. 현재 위치·남은 합의·다음 행동을 반환한다.
