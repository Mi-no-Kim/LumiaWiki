<a id="goal"></a>
## 목적과 허용 범위 및 완료 조건

- 부모 Issue: [Issue #15](<issue.md#goal>)
- 목적: P1의 자료 등록과 수용 조건 확인에 필요한 입력·순서·검증 방법을 정한다.
- 입력: [Task 001](<task-001.md#goal>)의 수용 조건, [Task 002](<task-002.md#goal>)의 화면·흐름, [Task 003](<task-003.md#goal>)의 공통 전제, [기존 입력 조사 근거](<#inherited-input-survey>).
- 결과 반영: 이 Task에 필요한 자료·부족 입력과 등록 흐름, 수용 조건별 확인 방향·대표 사례를 정리한다.

### 범위

- 필요한 자료의 종류, 기준 버전, 포함할 정보와 출처·시점 근거, 현재 제공 여부를 정리한다.
- 자료 확인 → 변환 → 교정 → 검증 → 등록 → 화면 확인의 큰 흐름을 정한다. 입력 전에 확인용 검색·상세 페이지를 마련하는 선행 관계를 유지한다.
- 시즌 1·v1.0.0 초기 등록과 자료 연결, 등록 내용의 조회 일치, 제작 관계·수량, 최소 루트 결과와 버전 보존의 확인 방향을 정한다.
- 수용 조건마다 확인할 화면·데이터, 기대 결과, 필요한 입력과 선행 과제를 연결한다.
- 제작 수량·공통 및 잔여 재료·배달 횟수·결과 없음 등 지원 범위에 필요한 대표 사례를 정한다. 이미 확정한 계산 규칙은 [루트 요구](<../../../../docs/details/product/루트 계산기.md#constraints>)를 따른다.

[실제 자료 확보·처리 보류](<../phase.md#input-workflow>)를 유지한다. 자료 조사·수집·변환·등록이나 제품 검증을 실제로 수행하지 않으며, 미제공 자료의 경로·값을 만들어 넣지 않는다.

### 완료 조건

- 필요한 자료와 제공 상태·부족 입력이 구별되어 있다.
- 등록·교정·확인의 큰 순서와 확인용 화면의 선행 관계가 정리되어 있다.
- Phase 수용 조건 전체가 확인할 화면·데이터·기대 결과·필요 입력과 연결되어 있다.
- 화면을 통한 기능 확인과 내부 계산·저장·참조 정합성 확인의 역할이 구분되어 있다.
- 지원 범위에 필요한 대표 사례가 있고, 자료 부족으로 아직 확인할 수 없는 부분과 이후 확인 조건이 명확하다.
- 계획한 검증과 실제 실행 결과를 구별하며 자료 보류를 해제한 것으로 처리하지 않는다.

<a id="plan"></a>
## 계획과 예정 검증

- 선행 조건: Task 001~003의 결과.
- 수행: 필요한 입력과 부족 정보 정리 → 등록·교정·확인 순서 정리 → 수용 조건과 검증 방향 연결 → 대표 사례와 이후 확인 조건 정리.
- 예정 검증: 수용 조건의 누락, 화면 확인을 내부 검사로 전부 대체한 항목, 실제 미수행을 성공으로 적은 부분, 보류한 자료 처리에 착수하는 항목이 없는지 대조한다.
- 후속 연결: [Task 005](<task-005.md#goal>)에서 자료 작업·화면·검증의 선행 관계를 후속 Issue에 배정한다.
## 기존 조사에서 인계받은 입력 근거

아래는 Phase에 있던 2026-11-01 조사 기록을 자료 계획의 입력 근거로 옮긴 것이다. 조사 범위·시점과 미확인 내용을 다시 확인할 때 필요하므로 이 Task에서 보관한다. 이 Task가 당시 조사를 수행했거나 현재 자료를 확보한 것으로 처리하지 않으며 상태는 예정으로 유지한다. 사용자가 제공한 미완성 SQL은 설계 참고이며 게임 수치 원자료와 구별한다.
<a id="inherited-input-survey"></a>
### 2026-11-01 입력 준비 현황 — 구현 착수 전 조사

| 자료/항목 | 확인 상태·근거 | 부족 입력/다음 확인 |
|---|---|---|
| 정식 출시·시즌1·v1.0.0 아이템 정보 | 현재 일반 작업 영역에서 실제 입력 파일을 찾지 못함. 루트 바로 아래 및 docs/harness/work의 xlsx/xls/csv/tsv/json/zip/sql 목록에 해당 파일 없음 | 실제 경로/URL, 출처·버전/시점 근거, 이름·분류·능력치·스킬 등 포함 정보 확인 |
| 조합법·획득 지역 | 별도 제공 위치/원자료가 현재 기록에 지정돼 있지 않음 | 재료/수량·완성품 관계, 획득 지역 범위와 v1.0.0 적합성 확인 |
| 배달 등 기본 루트 관련 조건 | 현재 요구/계획은 있음. 실제 값의 출처·버전은 미확인 | 필요한 정보와 최소 지원 범위를 진입/관련 Issue에서 정하고 자료와 대조 |
| 기존 요구·제품사양 보관본 | 문서가 있음. 요구/논의의 근거이며 실제 게임 수치 자료로 수용한 것이 아님 | 자료 제공과 요구 기록을 구별. 사용자 원본·ERD/ZIP 내용은 이번 입력 조사에서 열지 않음 |
| 외부 웹/엑셀·보존 자료 내부 | 미확인. 외부 자료를 제공/지정받거나 내용을 조사하지 않음 | 파일이 전혀 없다고 단정하지 않음. 지정받으면 접근·출처·시점/포함 정보부터 확인 |

이는 입력 현황 조사 결과이며 입력 확보/검증·변환·DB 등록·Phase 착수 완료가 아니다. 특정 형식·기술·테이블·옵션을 확정하지 않았다. 필요한 자료는 경로/URL과 출처·시점/버전 근거를 함께 제공받는다.
