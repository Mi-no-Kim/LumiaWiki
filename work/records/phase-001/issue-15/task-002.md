## 합의한 기본 화면과 논의 순서

2026-11-10 Task 001의 P1 범위·여섯 완료 조건과 이월 목록을 확인하고 Task 002에 착수했다. 사용자가 아래 세 기본 화면 구성을 선택했다. 별도 제작 관계 화면이나 전용 관리 화면은 추가하지 않으며 등록 자료 확인에도 같은 화면을 사용한다.

| 기본 화면        | 맡길 기능·구역                                                                                               | 다음에 정할 내용                                            |
| ---------------- | ------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------- |
| 아이템 검색·목록 | 첫 진입 목록, 자동 갱신·초기화, 이름·부위 기본 노출, 능력치·스킬 추가 필터, 간결한 목록과 미리보기·상세 진입 | 필터 세부·일치 규칙, 미리보기 상세·목록 분할 등 후속 디자인 |
| 아이템 상세      | 탭 없는 한 페이지의 핵심 정보·제작 관계·보조 정보 세 구역, 하위 전체·직접 상위와 수량·상세 이동              | 큰 트리·수량·미등록 정보의 세부 표현                        |
| 루트 계산        | 5개 부위 슬롯에서 화면 안 장비 검색·선택/교체/해제, 빈 슬롯 제외, 한 화면의 한도 입력·결과·정렬              | 선택창 상세·한도/정렬 기본값·오류별 상세 처리               |

P1 상세는 v1.0.0만 표시하고 버전 선택기는 후속으로 둔다. 루트 결과는 방문 순서가 아닌 지역 집합이다. 전용 정정 화면·후보 장비 조합 탐색·상세 스탯 조건·수식 계산을 이번 화면 범위에 앞당기지 않는다. 실제 자료 조사·처리 보류도 유지한다.

논의는 검색·목록의 대표 흐름 → 아이템 상세와 제작 탐색 → 루트 입력·결과 → 공통/재사용과 기능별 디자인 분담 순서로 진행하며, 구체화된 화면은 중간에 이미지로 확인한다. 기능 묶음별 디자인 범위는 아래 인계에 확정했으며 실제 담당 Issue의 구성·등록은 Task 005에서 수행한다.

2026-11-11 사용자는 검색 첫 진입부터 목록을 보여주고 이름·필터로 좁히는 방식을 선택했다. 검색 제외용 임시 아이템은 노출하지 않는 기존 규칙을 유지한다. 목록 분할·한 번에 표시할 개수는 이 선택으로 확정하지 않았다. 같은 요청에서 일정 분량이 정해지면 실제 화면 이미지까지 작성하도록 범위를 보완했다.

검색 조건은 이름 입력·필터 변경에 따라 자동 적용하고, 별도 검색 버튼으로 적용하지 않는다. 초기화하면 이름·필터 조건을 해제해 첫 진입의 기본 목록으로 돌아간다. 입력 반영 지연·요청 처리의 구현 세부는 이번 선택으로 확정하지 않는다.

검색 목록에서 아이템 상세로 이동한 뒤 목록으로 돌아오면 검색어·필터·스크롤 위치를 유지해 탐색을 이어간다. 초기화 동작과 목록 복귀는 구별하며, 상태 보관의 구현 방식은 후속 설계에서 정한다. 검색 결과가 없을 때 빈 상태를 보여주는 Task 001 합의는 유지하고 구체 표현은 상세 디자인에서 정한다.

목록의 아이템별 정보는 이미지·이름·등급·종류/장비 부위로 간결하게 두고, 능력치와 스킬 설명은 미리보기와 상세에서 확인한다. 아이템에 마우스를 올리면 미리보기를 보여주고 클릭하면 상세로 이동하는 기존 요구를 유지한다. 미리보기의 상세 배치·표시량은 아직 정하지 않았다.

이름 검색·장비 부위는 기본 노출하고, 능력치·아이템 스킬 관련 옵션은 접었다 펼치는 추가 필터에 둔다. 구체 옵션 목록·입력 방식과 일치 규칙까지 확정한 것은 아니다.

## 합의한 상세 화면 구성

탭으로 나누지 않고 한 페이지에서 아래 세 구역을 이어서 확인한다. 구역별 세부 배치와 디자인은 후속 검토에 남긴다.

| 구역      | 포함할 정보                                                      |
| --------- | ---------------------------------------------------------------- |
| 핵심 정보 | 이미지·이름·등급·종류/장비 부위, 능력치·아이템 스킬 설명         |
| 제작 관계 | 하위 조합법·최하위 재료의 총 필요량·직접 상위 아이템과 상세 이동 |
| 보조 정보 | 획득 지역·방법·배달 정보                                         |

P1의 v1.0.0 표시·제작 수량·미등록 정보의 빈 상태 요구는 유지한다. 하위 조합법은 처음부터 최하위 재료까지 재귀 트리 전체를 보여준다. 직접 재료만 보이고 사용자가 단계별로 펼치거나 '모두 펼치기'를 눌러야 전체가 보이는 제안은 채택하지 않았다. 최하위 재료의 총 필요량과 직접 상위 아이템의 확인·상세 이동 요구는 유지하며 수량의 세부 배치·표현은 후속 디자인에서 정한다. 패치 이력 등 제품 최종 요구의 후속 범위를 이번 구역 구성만으로 삭제하지 않는다.

제작 관계의 재료·상위 아이템을 클릭하면 해당 아이템 상세로 이동한다. 뒤로 가기는 직전에 보던 아이템 상세로, '목록으로'는 원래 검색어·필터·스크롤 위치를 유지한 목록으로 돌아간다. 탐색 이력·상태 보관의 구현 세부는 후속 설계에서 정한다.

## 합의한 루트 장비 선택과 첫 시안

무기·옷·머리·장식·다리의 5개 슬롯을 표시하고, 슬롯을 누르면 해당 부위의 장비를 검색·선택한다. 선택한 장비는 교체·해제할 수 있으며 빈 슬롯은 제외해 지정한 장비만 계산한다. 선택은 루트 화면 안에서 진행해 다른 입력을 유지한다. 선택창의 세부 배치·구현은 아직 정하지 않았다.

루트 계산은 '계산하기' 버튼으로 실행한다. 장비·지역/배달 한도를 바꿔도 자동 재계산하지 않고, 기존 결과가 있으면 '변경 전 조건의 결과'로 표시한다. 다시 계산을 실행해 새 결과를 얻으면 이를 교체한다. 검색 목록의 입력 변경에 따른 자동 갱신과 구별한다.

루트의 주요 상태는 아래 구성을 우선 기본 처리안으로 채택한다. 세부 문구·입력 검증 규칙·오류별 상세 복구는 후속 기능 설계에서 정한다.

| 상태      | 기본 처리                           |
| --------- | ----------------------------------- |
| 계산 전   | 장비·조건 입력 안내                 |
| 입력 오류 | 문제 위치를 안내하고 계산 실행 차단 |
| 계산 중   | 진행 표시·중복 실행 방지            |
| 결과 없음 | 조건에 맞는 결과가 없음을 안내      |
| 실행 실패 | 계산 실패를 알리고 재시도 가능      |

결과 없음과 실행 실패를 구별하며 조건을 자동으로 완화하지 않는다. 위 상태 구분은 Task 001에서 지원한 전체/일부 부위 계산과 미정인 입력 한도 기본값을 바꾸지 않는다.

- [루트 화면 이미지 v1](artifacts/task-002-route-v1.png) · [생성 조건·최종 프롬프트](artifacts/task-002-route-v1.prompt.txt)
- 내장 이미지 생성 도구로 검색 v2의 스타일을 참조해 작성했다. 두 부위만 장비를 지정한 상태와 세 빈 슬롯, 입력 한도·계산 결과·정렬을 한 화면에 배치했다. 방문 지역은 순서 없는 집합으로 표현했다.
- 사용자는 루트 v1을 현재 기준안으로 채택하고 배치의 디자인 상세는 나중에 조정하기로 했다. 계산 버튼 실행은 후속 논의에서 확정했으며 입력 한도 기본값·정렬 기본값은 미정이다. 시안의 한도 2/1과 아이템·지역·재료·수치·결과는 모두 예시다. 캐릭터 필수 선택·후보 장비 조합·상세 스탯 조건·임의 보유 수량 입력을 추가하지 않았다.
- 슬롯·빈 부위·지역 집합·결과 항목을 기존 합의와 육안 대조했다. 실제 게임 자료 확인·루트 계산 실행·알고리즘 검증을 수행한 결과가 아니다.
