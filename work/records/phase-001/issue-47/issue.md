## 기본 루트 계산

<a id="task-outline"></a>
### Task 구성 윤곽

Task는 아직 생성하지 않았다. 아래 표는 합의한 구성 윤곽이며 실제 Task 등록·파일 작성과 상세 실행/검증 계획은 이 Issue를 준비할 때 진행한다.

| Task 제목 윤곽 | 만들 결과·선후 관계 |
|---|---|
| 루트 입력·결과 화면 설계 | 공통 아이템 표현을 재사용해 슬롯 선택·한도·계산 상태·지역 집합·재료/배달 결과·정렬을 먼저 디자인·검토 |
| 장비 선택·조건·계산 상태 | 5부위 선택/교체/해제·빈 슬롯 제외·한도 입력·계산 버튼·조건 변경 후 이전 결과 표시와 주요 상태를 연결 |
| 지역 집합·수집/배달·능력치 계산 | 제작 필요량을 재사용해 실제 최초 보유·공통/잔여 재료·획득 가능 지역·배달 수량·기본 능력치 요약을 계산. 알고리즘·가공/캐시 갱신과 임시 아이템의 루트 취급을 결정·검증 |
| 결과 표시·정렬·자료 수정 반영 | 실제 계산 결과와 상태를 화면에 연결하고 지역 수/배달 횟수 정렬·결과 없음/실패·재시도·교정 후 재계산을 확인 |

<a id="acceptance"></a>
### 합의한 수용 조건

- 실제 자료로 전체/일부 장비 목표와 지역/배달 한도를 적용해 지역 집합·수집/배달 재료와 수량·배달 횟수·기본 능력치가 맞는다. 최초 보유·수율·잔여와 배달 올림을 반영한다.
- 버튼 실행·조건 변경 전 결과 표시·재계산 교체와 계산 전/오류/계산 중/결과 없음/실패를 구별한다. 지역 수·배달 횟수 정렬과 입력 한도 경계를 확인한다.
- 자료 교정 뒤 관련 계산 결과가 일치한다. 방문 순서 최적화·후보 장비 조합·상세 스탯 조건·임의 보유 수량·스킬 수식 계산은 P1에 추가하지 않는다. 출현 총량·배달 비용은 계산에서 제외한다.

<a id="pending"></a>
## Task 선후 관계와 남은 결정

- 화면 설계 뒤 장비/조건/계산 상태를 연결하고 필요량·최초 보유·획득/배달 입력을 바탕으로 계산한다. 실제 결과·정렬·실패/재시도와 교정 후 재계산까지 연결한다.
- 알고리즘·가공/캐시·임시 아이템 취급·한도 범위/기본값·기본 능력치 합산·결과 배분·정렬 기본/동률·입력 오류/복구는 기능 구현 전에 결정한다.
- 실제 자료가 없는 동안 허용된 준비·통제한 입력 실험은 가능하지만 그 결과만으로 실제 자료의 루트 계산 정합성을 수용하지 않는다.
