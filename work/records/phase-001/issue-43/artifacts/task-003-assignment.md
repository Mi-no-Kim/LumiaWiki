# Task 43-003 배정 개정 — 장착 부위 정정

<a id="equipment-slot-revision"></a>

- 근거는 [Issue #43의 배정 개정](../issue.md#equipment-slot-assignment-revision)이다. 최초 배정은 `d6adc6f`의 [Task 43-003](https://github.com/Mi-no-Kim/LumiaWiki/blob/d6adc6f0eaf3a3111a09ea14e37ba6491f378dc1/work/records/phase-001/issue-43/task-003.md#goal)이다.
- 장착 부위의 저장 입력과 아이템 버전 컬럼을 제거한다. 조회는 해당 버전의 `category_id`와 현재 분류 계층에서 부위를 판별한다. 장비 그룹과 부위는 종류 ID의 역할로 기록하고 이름이 바뀌어도 유지한다. 상위 계층은 한 조회에서 읽고 순환 경로는 중단한다. 정정을 격리 검증한 뒤 제작·획득·배달 작업을 이어간다.
- 허용 범위는 후속 마이그레이션 작성, Spring과 테스트 수정, 합성 자료를 사용하는 격리 검증이다. 기존 개발 DB 적용과 실제 자료 작업은 보류한다.
- 수용 조건은 빈 DB 설치와 합성 V3 환경의 갱신에 성공하고, 장비 5개 부위·비장비·과거 버전의 분류와 기존 값·참조를 확인하는 것이다. V3 저장 부위와 분류가 다른 사례에서 분류를 조회 기준으로 사용한다. 같은 분류 ID의 이름을 바꿔도 조회 부위가 유지되고, 분류를 동시에 재배치해도 조회가 한 계층을 기준으로 종료되는지 확인한다.
