## 현재 상태와 적용 범위

담당 상태·완료 조건은 [Task 43-001](../task-001.md#summary)이 소유한다. Task는 진행 중이며 이 문서들은 설계·선택 근거다. 최초 구동 구현과 격리 DB 검증은 [검증 기록](task-001-bootstrap-verification.md#results)을 따른다. 실제 자료·기존 개발 DB/볼륨과 공통 도메인 표 구현은 보류한다. 새 업무 선택은 대안·추천 이유를 먼저 제시하고 사용자 응답 전에 확정하지 않는다. DB 파일과 목적별 설명은 [DB 안내](../../../../../db/README.md#current)에서 찾는다.

## 현재 적용할 계약

- 공유 관계는 버전별 귀속 행·재료 대상/버전 직접 참조·영향받는 상위 구성 새 버전·기존 스킬 버전 재사용을 따른다. 종류 이름/계층은 버전 없는 현재 기준이다.
- 공통 키/필수값/참조·PK 보호와 M1~M3·8개 표/N1~N5·패치 번호 각각 0~99는 확정 계약이다. D1 NULL 등록·D2 중복 금지·D3 일대일 FK·D4 지도 구성/이력을 유지하며 실제 목록/값·제약별 이름/정확한 실행 환경과 실행 검증은 남아 있다.
- 일반 갱신은 Spring, DB는 무결성 검사, Python은 적합한 개별 작업만 담당한다. 등급 수정은 관리자 판단·기본 검사다.
- 최초 구동은 최초 설치 검증/기본 기동을 사용한다. 계정/고정 권한·B2/B3는 유지하고 매 기동 전수 검사/각 5초는 제외한다.
