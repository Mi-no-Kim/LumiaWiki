# Task 43-001 — 공통 도메인 구현과 DB 없는 검증

<a id="current"></a>

담당은 [Task 43-001](../task-001.md#summary)이다. 기준 커밋은 49c39d4이며 합의한 8개 표·N1~N5·패치 번호 각각 0~99를 구현한다. 사용자가 구현 파일 생성과 검증을 허용했고 전체 구조/대상 확인 뒤 새 격리 검증과 승인한 로컬 적용을 마쳤다. 현재 DB 실행 근거는 [생성 기록](task-001-creation.md#verification)이 소유하며 실제 자료 작업은 계속 보류한다.

## 구현 전 확인 목록

- 시즌 번호/정렬·패치 0/99 경계와 범위 밖 거부, 별도 실제 이름/날짜 NULL 보존.
- 날짜 역전/빈 이름 거부와 적용 시각의 UTC 초 단위 절삭.
- 종류 부모 변경의 잠금 후 최신 트리 순환 검사.
- 지도 구성의 지역/이름/순서 중복·없는 지역 거부, 미확인 지도와 확인된 빈 지도 구별.
- 작업용 지역 이름만 수정할 때 공개 이름·지도/획득 참조 유지.
- 알려진 업무 제약 오류와 예상 밖 PK guard 실패 구별, 후속 참조 검사 실패 전달.
- JPA/DDL의 실제 DB 검증·권한·트랜잭션/잠금/롤백·SQL 실행은 생성 직전 전체 구조/정확한 대상 확인 후 수행. Mockito 기반 검사를 이 검증으로 대신하지 않음.

## 구현·후속 경계

새 HTTP API·관리 화면은 추가하지 않는다. 공통 표의 저장/조회와 협력 잠금을 구현하며 후속 획득 본행·유효 구간·결합 검증은 003/004가 담당한다. 후속 자료가 생기기 전 해당 참조 검사 연결과 통합 검증이 필요하다.

<a id="verification"></a>

## 현재 결과와 남은 검증

DDL·14개 Java 모델/저장소/서비스 파일과 DB 없는 서비스/저장소 테스트를 작성했다. 최종 동작 cycle은 READ COMMITTED 기대의 실제 assertion 실패 후 16건 Green을 확인했고 확장된 전체 단위 30건(신규 21·기존 9)이 통과했다. 도구 테스트 9건과 검증 스크립트 구문 검사도 통과했다. 실제 DB의 후속 검증/로컬 적용은 [생성 기록](task-001-creation.md#verification), 단위/TDD 증거는 아래 cycle이 소유한다. 실제 게임 자료는 조회하지 않았다.

- DDL 정적 대조: 8개 표·8개 IDENTITY/PK guard·6개 비지연 FK와 60개 제약 이름. 26개 업무 오류 매핑 이름이 실제 DDL에 존재하며 나머지는 예상 밖 오류로 유지한다. 정적 검사 자체를 실행 증거로 확대하지 않으며 실제 DB 검증과 구별한다.
- Spotless와 bootJar가 통과했다. JAR의 V1 SQL은 원천 SHA-256 1495d8a5085188f535865f9b46f51aa1c9a18480c1b49efd68df61c43f5b8ddd와 일치하며 테스트 fixture/합성 probe SQL은 포함하지 않는다. 동일 JAR로 승인한 로컬의 Flyway 적용과 app JPA validate를 확인했다.
- DB 없는 Spring 프록시/대체 트랜잭션 관리자의 격리·롤백 호출 확인은 실제 DB 롤백/잠금 증거가 아니다. 후속 003/004의 검사 연결은 해당 자료 저장 전에 필요하다.
- 무기 종류/아이템 종류와 지도 버전/시작 패치는 DB UNIQUE에 맞춰 JPA OneToOne으로 표현한다. 매핑 정리 전후 DB 없는 단위 30건을 확인하며 표·열·참조 개수는 변경하지 않는다.
- 기존 foundation/probe 테스트는 전용 fixture/합성 SQL·빈 entity 패키지로 구분했고 최초 구동 사본은 catalog 소스를 제외한다. 기존 격리 통합 검사 6건을 포함한 전체 통합 11건을 재검증했다. 별도 프로브 도구 자체의 재실행과는 구별한다.
- [전체 구조/정확한 대상 확인](../../../../../db/migration/README.md#precreation-confirmation)을 받아 새 격리 검증 뒤 로컬에 적용했다. 후속 신규 구조도 재확인한다. 최종 수용/검수와 후속 인계는 [생성 기록](task-001-creation.md#acceptance)을 따른다.
