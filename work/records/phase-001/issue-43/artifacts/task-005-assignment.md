## Task에서 결정할 사항

- 결정할 사항: `catalog`에 직접 연결된 공통 코드·테스트·설정을 어디까지 부분 복원하거나 유지할까?
  - 결정 범위: `ApiFailure`의 `catalog` 전용 확장, 부트스트랩 테스트, Flyway·JPA 및 실행 연결 설정의 파일별 처리.
  - 판단 기준: 잔여 참조 없이 빌드되고 기존 공통 오류 응답 및 DB 설치·갱신·역할 검증이 유지된다.
  - 결정 주체: 사용자가 변경 범위를 확정하며, AI는 근거와 파일별 후보를 제시한다.
- 결정할 사항: 로컬과 원격 #43의 차이를 고려해 어떤 순서로 제출할까?
  - 결정 범위: PR 기준 브랜치와 상위 변경 반영·정정 제출의 순서.
  - 판단 기준: 실제 원격 HEAD와 PR diff를 대조하고 상위 반영이 정정 PR의 범위에 섞이지 않게 한다.
  - 결정 주체: AI가 원격 상태와 분리안을 확인해 제시하고, 실제 원격 반영 범위는 사용자와 확정한다.
