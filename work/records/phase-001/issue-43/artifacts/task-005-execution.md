## 공통 API와 격리 DB 검증

- 할 일: [공통 API와 격리 DB 검증](task-005-plan.md#stage-verify)
- 조치·판단: 포맷 검사, 단위 테스트와 격리 통합 테스트, 실행 JAR을 확인했다. 새 Task 워크트리의 CRLF 체크아웃은 해당 Java와 SQL의 정규 Git 바이트로 맞췄으며 보존 대상의 Git diff는 없다.

- 확인: PostgreSQL 18.6의 빈 DB `8d61b95852be`와 V1 백업 복원 DB `63c304280ad5`에서 앱 JAR을 각각 기동했다. 두 경로 모두 기반 API HTTP 200, Flyway V1~V5 성공과 기존 체크섬 5개, 제품 표 16개의 소유·적용 SQL에 따른 앱 권한, 획득 FK 5개와 배타 제약 1개를 확인했다. V1 경로에서 기존 표 8개와 FK 6개를 보존했다. 백업의 제품 행은 0건이어서 비어 있지 않은 데이터의 보존은 이번 근거로 판단하지 않는다.
- 잔여: 공유 개발 DB는 시험 대상으로 사용하지 않았다. 원격 제출 및 #43의 전체 수용은 이후 결정이다.
