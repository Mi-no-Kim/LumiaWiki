  1. [확정한 R2 재료 기준](artifacts/task-001-version-references.md#r2-read-priority)에 따라 재료의 아이템 ID·실제 읽을 버전 ID와 영향받는 상위 구성 새 버전 준비를 관계 계약의 전제로 둔다. 두 재료·생산 수량과 기본 재료/조합 자료 누락을 구별하는 저장·조회 후보, 지역/방법·사냥 대상·임시 아이템 연결 후보를 정리해 먼저 사용자에게 요청한다. 실제 사냥/임시 대상과 적용 사실은 #45 입력으로 확인한다.
  2. 한 번의 제작은 재료 A/B를 각 1개 소비하고 같은 버전의 대체 조합법은 없다는 합의를 유지한다. 획득/배달당 공통 수량·제작 결과 수량·지역별 총 출현 개수를 구별하며 임의의 별도 수량 필드를 추가하지 않는다.

### 조건부 항목의 적용 판단과 기록

- 실제 자료 의존: 필요한 값·관계가 아직 미확인이고 자료 작업 보류가 적용된다. [자료 단계](issue.md#data-timing)와 아래 미정 표를 기준으로 #45의 입력 확인이 필요한 범위를 구분하며, 보류 해제·입력 확인 전에는 의존하는 설계값·구현·완료 판정을 확정하지 않는다.
- 화면·확인 경로: 저장·조회 확인 경로의 구체 선택이 남아 있다. [공통 검증 경계](issue.md#execution)를 유지하고 새 API/개발용 화면 등 선택이 필요하면 범위·대안·영향을 사용자에게 먼저 제시해 결정받는다. 응답 전에는 해당 동작을 구현하지 않는다.
- 별도 검수: [별도 검수 기준](../../../../docs/details/operations/별도 검수.md)에 따른 커밋 전 검수는 실제 커밋 준비 때 적용한다. 현재 요청은 공유 관계의 사용자 선택 반영이며 커밋·운영 규칙 변경을 수행하지 않는다.
