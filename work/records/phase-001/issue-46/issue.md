## 목표와 범위

## 제작 관계와 재료 수량

<a id="task-outline"></a>

### Task 구성 윤곽

Task는 아직 생성하지 않았다. 아래 표는 합의한 구성 윤곽이며 실제 Task 등록·파일 작성과 상세 실행/검증 계획은 이 Issue를 준비할 때 진행한다.

| Task 제목 윤곽             | 만들 결과·선후 관계                                                                                                                                      |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 제작 구역 화면 설계        | 기본 상세와 공통 표현을 재사용해 전체 하위 트리·총량·직접 상위·이동·미등록 상태를 디자인·검토                                                            |
| 관계 조회와 아이템 탐색    | 조회 패치가 일치하는 하위/직접 상위 관계와 상세 이동을 구현. 기본 재료/누락·순환 처리 연결                                                               |
| 재료 합산 대안 실험과 선택 | 조합으로 계산하는 방식과 item_leaf_materials 등 저장 방식을 실제 입력/통제한 경계 입력으로 반복 실험. 수량 정확성·잔여·정정 갱신·조회 부담을 근거로 선택 |
| 총 필요량 계산과 화면 연결 | 선택한 방식으로 반복 재료·제작 수율·올림·잔여를 반영해 총량을 표시하고 루트가 사용할 필요량 계산 결과를 제공                                             |

<a id="acceptance"></a>

### 합의한 수용 조건

- 상세에서 최하위 재료까지 하위 트리를 처음부터 모두 보여주고 제작 1회 수량·총 필요량·직접 상위와 상세 이동/복귀가 작동한다.
- 실제 조합법과 통제한 경계 입력에서 반복·수율·잔여·여러 단계 계산이 일치한다. 누락을 0개로 계산하지 않고 순환으로 무한 계산하지 않는다.
- 합산 방식의 실험·선택 근거가 있고 관련 자료 교정 뒤 관계·총량과 필요한 가공/캐시가 일치한다. 루트가 같은 필요량 계산을 재사용할 수 있다.

<a id="pending"></a>

## Task 선후 관계와 남은 결정

- 제작 화면 설계를 먼저 검토하고 관계 조회/탐색을 연결한다. 재료 합산 대안 실험·선택 뒤 총 필요량 계산을 완성한다. 관계 조회와 실험의 독립 부분은 병행할 수 있다.
- 실험 입력·환경·반복 횟수·판정 기준, 순환/누락 처리·큰 트리/수량 표현·item_leaf_materials 채택/갱신은 담당 실행 계획과 설계에서 결정한다.
- 자료 교정에 따른 관계·총량·가공/캐시 일치를 이 Issue에서 확인하고 [루트 Issue](../issue-47/issue.md#route)에 필요량 계산 결과를 연결한다.
