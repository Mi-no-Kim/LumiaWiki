# 시험용 전달사항

- 태그: 조사, 논의, 결정, 실행, 검수

## 목적

시작 안내의 링크·중복을 정리하고 선택·확인 근거를 남긴다.

## 기대 결과

시작 안내의 링크·중복을 정리하고 선택·확인 근거를 남긴다.

## 이미 정해진 조건

이 문서의 허용 대상·선행 입력·완료 조건을 따른다. 모의 사용자 사건은 실제 사용자 승인으로 쓰지 않는다.

## Task에서 결정할 사항

주어진 선택·위임 범위 안에서 판단하고 미제공 결정은 만들지 않는다.

## 완료 조건과 확인 방법

다음 조건 정의를 실제 파일·선택 근거와 대조한다. 생성 입력의 사본을 Task 현재 값으로 바꾸지 않는다.

```json
{
  "allowed_writes": [],
  "required_sources": [
    "guide.md"
  ],
  "criteria": [
    {
      "id": "source",
      "kind": "exists",
      "path": "guide.md"
    },
    {
      "id": "link",
      "kind": "links",
      "path": "start.md"
    },
    {
      "id": "choice",
      "kind": "choice",
      "value": "A"
    }
  ]
}
```
