## 실제 검증과 한계

- 후보 전체 회귀 **106개 통과**. 기존 전체 제안의 114개와 후속 26개는 범위가 달라 수 증감을 개선율로 비교하지 않는다. 여기에는 새 길이 회귀 6개와 진단 회귀 1개가 포함된다.
- 통합 직접 호출 **12개**가 기대 결과를 충족했다. 정상·위반 work/index 구별, JSON block·복구, 정확한 위반 파일명과 자동 원복 없음, 선택적 과거 보호 정책을 확인했다.
- 원래 저장소에 대한 읽기 전용 patch 적용 검사 **3개**와 로컬 참조 **144개**를 통과했다. 실제 구현을 원래 작업 파일이나 index에 적용하지 않았다.
- 별도 읽기 전용 검수에서 선택 조합의 누락·보류 기능 잔류·추가 필수 결함을 찾지 못했다. 실제 실행 결과와 최종 기록은 주 진행 AI가 다시 대조했다.
- [명령·관찰·판정 원문](verification.json)의 첫 호출에 전체 106개 로그가 있다. 내부 경로는 `.tmp/issue-task-pilot-2/phase-1/` 기준이다. 실제 원격 skill 자동 선택·hook 자동 발동·정식 객체 발급과 부모 수용의 증거로 확대하지 않는다.
