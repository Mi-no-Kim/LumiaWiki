# 이전 작은 작업 진행 규칙의 연결 안내

작은 작업은 Task 안의 할 일로 유지한다. 진행 규칙은 [Task 공통 절차](../task-common-procedure-draft.md)로, 예정·수행 기록의 양식과 예시는 [본문 양식](../task-body-template-draft.md)으로 통합했다. 이 파일은 이전 링크를 위한 안내이며 별도 규칙을 두지 않는다.
