# 이전 수행 문서 양식의 연결 안내

수행 기록은 Task당 한 파일에 할 일별 구역을 둔다. 실제 양식과 연결 예시는 [본문 양식](../task-body-template-draft.md#execution-body)으로 통합했다. 이 파일은 이전 링크를 위한 안내이며 별도 양식을 두지 않는다.
