# 시험용 Task T 전달사항

- 태그: 조사, 실행, 검수

<a id="purpose"></a>
## 목적

상세 문서를 이동하고 들어오고 나가는 현재 링크·표식·본문 보존을 확인한다.

<a id="result"></a>
## 기대 결과

상세 문서를 이동하고 들어오고 나가는 현재 링크·표식·본문 보존을 확인한다.

<a id="scope"></a>
## 이미 정해진 조건

guide.md를 guides/recording.md로 이동하고 start.md·index.md·이동 문서의 링크를 보정한다. 본문·표식·추가 문장은 보존한다.
조건의 근거는 [시험용 부모](parent.md#assignment)다. 모든 사용자 역할 사건은 모의 입력이다.

<a id="decisions"></a>
## Task에서 결정할 사항

사례에서 맡긴 선택만 결정한다. 필요한 응답은 승인된 모의 입력으로 제공하며 실제 사용자 승인으로 쓰지 않는다.

<a id="acceptance"></a>
## 완료 조건과 확인 방법

이전 파일이 새 위치로 이동하고 start.md·index.md·이동 문서의 세 현재 링크가 최종 위치에서 유효하다. 기존 표식·본문·범위 밖 내용을 보존한다. 상세 설명 중복 해소는 맡기지 않는다.
