# 시험용 Task T 전달사항

- 태그: 조사, 논의, 결정, 실행, 검수

<a id="purpose"></a>
## 목적

시작 안내의 잘못된 링크와 상세 설명 중복을 정리하고 선택·확인 근거를 남긴다.

<a id="result"></a>
## 기대 결과

시작 안내의 잘못된 링크와 상세 설명 중복을 정리하고 선택·확인 근거를 남긴다.

<a id="scope"></a>
## 이미 정해진 조건

두 원문을 읽고 start.md와 guide.md의 첫 상세 문장을 함께 수정한다. 나머지 원문·범위 밖 내용은 보존한다. 안내 방식은 모의 사용자 선택 뒤 반영한다.
조건의 근거는 [시험용 부모](parent.md#assignment)다. 모든 사용자 역할 사건은 모의 입력이다.

<a id="decisions"></a>
## Task에서 결정할 사항

사례에서 맡긴 선택만 결정한다. 필요한 응답은 승인된 모의 입력으로 제공하며 실제 사용자 승인으로 쓰지 않는다.

<a id="acceptance"></a>
## 완료 조건과 확인 방법

실제 링크 대상 파일·표식, 두 상세 문장의 중복 제거, 선택 입력과 반영 일치, 원문·범위 밖 내용 보존을 대조한다. 중단·취소·부분 진행에서는 이 전체 목표의 미충족·잔여를 유지한다.

개정 근거: 모의 사용자 역할이 두 문서 수정·새 완료 조건·범위를 확정했다. guide.md의 첫 문장은 “Task 본문에는 현재 상태·계획·유효한 결정을 정리합니다.”로 바꾸고 두 문서 결과를 대조한다.
