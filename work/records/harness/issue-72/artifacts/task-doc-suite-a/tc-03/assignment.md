# 시험용 Task T 전달사항

- 태그: 조사, 논의, 결정, 검수

<a id="purpose"></a>
## 목적

두 문서의 링크 점검 방법을 비교하고 가상 사용자 선택·이유·후속 조건을 정리한다.

<a id="result"></a>
## 기대 결과

두 문서의 링크 점검 방법을 비교하고 가상 사용자 선택·이유·후속 조건을 정리한다.

<a id="scope"></a>
## 이미 정해진 조건

원문 검토·비교·논의만 허용한다. 두 방법을 재현 가능성·준비 부담·두 문서의 확인 범위로 비교한다. 검사기 작성·실행·문서 수정은 맡기지 않는다.
조건의 근거는 [시험용 부모](parent.md#assignment)다. 모든 사용자 역할 사건은 모의 입력이다.

<a id="decisions"></a>
## Task에서 결정할 사항

사례에서 맡긴 선택만 결정한다. 필요한 응답은 승인된 모의 입력으로 제공하며 실제 사용자 승인으로 쓰지 않는다.

<a id="acceptance"></a>
## 완료 조건과 확인 방법

수동 대조와 로컬 검사 방식을 재현 가능성·준비 부담·이번 두 문서의 확인 범위로 비교한다. 가상 선택·이유·후속 조건을 기록한다. 검사기 실행·문서 수정 성공은 조건이 아니다.
