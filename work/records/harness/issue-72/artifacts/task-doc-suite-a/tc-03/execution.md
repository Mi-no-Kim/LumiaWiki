## 방법 비교

- 할 일: [방법 비교](task.md#work-compare)

- 조치·판단: 실제 두 원문을 읽고 수동 대조와 로컬 검사 방식을 같은 기준으로 비교했다.
- 확인: 수동은 대상 두 파일·표식의 절차를 지정하면 재현할 수 있고 추가 실행 환경이 필요 없다. 로컬 검사는 정의·환경 준비와 오탐 범위 확인이 필요하며 구현·실행하지 않았으므로 실제 검출 능력은 미확인이다. 이번 두 문서의 경로·표식 비교에는 수동 대조를 적용할 수 있다.
- 잔여: 없음

<a id="work-choose"></a>
## 방법 선정

- 할 일: [방법 선정](task.md#work-choose)

- 조치·판단: 모의 사용자 역할이 수동 대조를 선택했다.
- 확인: 선택·이유·후속 입력 조건을 기록했다. 후속 점검에 필요한 입력은 점검할 두 문서의 실제 원문·파일 위치다. 수동 대조의 대상은 링크의 파일·표식이며 파일 변경·검사기 구현·실행은 이번 선정 배정의 허용이 아니다. 실행이 필요하면 해당 실행의 범위·허용과 입력을 먼저 확인한다.
- 잔여: 없음
