# Issue → Task 생성 시험 중단 근거

- 현재 판정: 목적·관찰 대상·방법·입력과 판정 기준의 사전 합의 없이 AI가 설계·실행한 시험이다. 사용자 지적에 따라 중단했으며 수용·생성 흐름 검증 성공의 근거에서 제외한다.
- 실제 실행 범위: A~F의 반환을 받았고 진행 중이던 G는 중단했다. 유효한 시험 완료·통과로 판정하지 않는다.
- 보존 범위: 아래 공통 지시·일곱 원입력·원천 지문은 AI가 임의로 정한 당시 조건을 확인하는 자료다. 합의된 시험 계획이나 다음 실행의 입력으로 채택하지 않는다. 반환 전문은 이 파일에 보존돼 있지 않다.
- 다음 행동: 무엇을 확인할지, 어떻게 관찰·판정할지, 어떤 입력을 사용할지 먼저 사용자와 정한다. 그 합의 전 시험을 재개하지 않는다.

- 실행 ID: task-generation-7d3a91c2
- 담당: [Issue #72](../issue.md#task-generation-test)
- 범위: 사용자가 이전 Issue 생성 테스트처럼 입력별 새 문맥의 별도 에이전트 실행을 요청했다. 각 문맥에 아래 공통 지시와 해당 원입력만 제공하고 기대 답안·이전 결과는 제공하지 않는다.
- 방법: 같은 모델의 역할·문맥 분리 시험이다. 현재 작성안을 명시적으로 적용하여 메모리에 실제 전달사항·Task 본문·부모 연결안을 구성하거나 필요한 보완을 반환한다. 전용 Task 생성 skill·자동 선택·실제 파일 생성·발급·등록·제품 수행은 시험하지 않는다.
- 가상 경로·확정·권한·충돌 확인은 시험 입력이며 실제 #42의 상태나 승인 사실이 아니다. 실제 저장소에는 Task·배정 파일을 만들지 않는다.
- 비교 기준: HEAD `2992008c7de4eb11b843fa0d2f89e62352b657bc`. 시험 전 실제 index SHA-256 `5bde1d3b3a20add676173b23304919eaf08af158921526867d580c90b959a4e1`; 실제 index의 스테이징 차이는 없다. index 읽기 확인 전에 시도한 `git write-tree`는 index.lock 권한 거부로 종료했으며 결과를 확인 근거로 사용하지 않는다.
