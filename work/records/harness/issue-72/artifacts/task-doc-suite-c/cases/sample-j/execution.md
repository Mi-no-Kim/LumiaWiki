<a id="work-inspect"></a>
## 기존 원문 대조

- 할 일: [본문](task.md#work-inspect)

- 조치·판단: 가상 사전 상태 입력: 원문 대조가 끝난 기존 기록이다. 이번 실행에서 과거에 수행한 사실이 아니다.
- 확인: `{"판정": "충족", "관찰": "입력에서 start의 record 링크와 실제 recording 표식 불일치 및 상세 두 문장의 중복이 확인돼 있다."}`
- 잔여: 없음

<a id="work-choose"></a>
## A/B 후보의 차이와 계획을 논의하고 안내 방식을 선택한다

- 할 일: [본문](task.md#work-choose)

- 조치·판단: 기존 가상 사전 상태의 원문 대조 완료 근거를 확인하고 그대로 보존했다. 미착수 link·intro를 각각의 확인까지 포함해 link 한 반영·확인 단위로 실제 병합했다. choose→병합 link→close 순서로 의존 관계를 유지했다.
- 확인: `{"판정": "미확인", "관찰": "계획의 활성 할 일은 inspect·choose·link·close 네 개다. intro는 link에 병합한 대응을 현재 합의에 보존했다. inspect 완료 기록은 원문 그대로이며 실제 대상 파일도 입력 원문과 동일하다. A/B 응답은 제공되지 않았다."}`
- 잔여: 이번 관찰은 계획 조정까지이며, 선택과 반영은 후속 허용 범위에서 판단한다.
