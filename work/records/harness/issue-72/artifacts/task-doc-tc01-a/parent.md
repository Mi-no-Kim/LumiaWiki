# TC-01 시험용 부모 P — 시작 안내 정비

이 파일은 가상 부모 역할의 시험 입력·관계·전체 수용 기록이다. 실제 GitHub Issue나 #72의 정식 하위 Task가 아니다.

- 실행 식별: task-doc-tc01-a
- 실제 담당 기록: [Issue #72](../../issue.md#task-generation-test)
- 적용 사례: [TC-01](../task-document-management-test-cases.md#case-01)
- 실행 방식: 현재 대화의 같은 AI가 작성안을 적용하고 실제 로컬 파일을 확인한다. 기대 결과를 아는 상태의 사용 확인이며 맹검·새 문맥·자동 생성기의 독립 검증이 아니다.
- 사용자 지시: “저 사례가 적절한지 확인해. 그리고 사용해봐”. 사례의 검수·사용과 제안한 TC-01 흐름 안의 준비·생성·논의·조건부 반영·확인을 수행한다. 문안의 사용자 선택을 대신하지 않는다.
- 상태: 완료
- 현재 위치: [전체 수용과 결과](#acceptance)
- 다음 행동: 실제 담당 Issue의 현재 시험 판단과 후속 사례 범위를 확인한다.

<a id="setup"></a>
## 시험 파일 대응과 허용 범위

| 역할 | 이 폴더의 파일 |
|---|---|
| 가상 부모 P | parent.md |
| 가상 자식 T | task.md |
| 확정 전달사항 | assignment.md |
| 첫 할 일 착수 때 만들 수행 기록 | execution.md |
| 수정할 시험 입력 | start.md |
| 읽기 전용 상세 원문 | guide.md |

이 폴더는 생성 전 존재하지 않았고 새 파일의 충돌이 없음을 확인했다. P·T는 역할 기호이며 실제 번호·순번 확인이나 GitHub 등록을 대체하지 않는다. 식별·경로 연결은 이 시험 묶음 안에서만 확인한다. 정식 경로·번호 발급·원격 관계의 동작은 이번 판정 범위 밖이다.

<a id="assignment"></a>
## 배정 기준 기록

- 적용 원본: [전달사항](assignment.md)
- 전달본 식별: r001 — 이 시험 안에서 초판을 확정했다.
- 확정 근거: 사례의 기준 배정과 위 사용자 사용 요청을 이 시험의 범위로 적용했다. 안내 방식은 Task에서 실제 사용자에게 확인한다.
- 배정 경계: 시험용 두 원문을 읽고 start.md만 수정한다. guide.md의 내용은 보존한다. 수정은 안내 방식의 선택 뒤 수행한다. AI에는 대조·후보 작성·합의 안의 문안 정리·검증 방법을 맡긴다.

<a id="acceptance"></a>
## 전체 수용과 결과

Task가 준비한 결과를 읽어 링크 연결·상세 설명의 중복 해소·사용자 선택 반영·상세 원문과 범위 밖 내용 보존을 각각 확인한다. 자식 완료나 할 일 체크만으로 이 부모를 완료하지 않는다.

- 전체 수용: 충족 — 시험 진행 AI가 가상 부모 역할에서 [Task 결과](task.md#result)와 실제 두 입력 파일·사용자 선택을 별도로 대조했다. Task가 완료됐을 때 이 부모는 아직 진행 중이고 전체 수용은 미판정인 상태임을 먼저 확인했다. 이후 아래 결과 조건을 대조해 이 시험용 부모를 완료로 판단했다. 실제 제품 Issue의 수용이나 사용자의 전체 결과 승인으로 확대하지 않는다.

| 전체 수용 조건 | 별도 대조 결과 | 근거 |
|---|---|---|
| 링크 연결 | guide.md#recording과 실제 표식이 일치 | [반영·확인](execution.md#work-apply)과 실제 start.md·guide.md |
| 중복 해소 | 두 상세 문장은 상세 원문에만 남음 | 실제 두 문서 대조 |
| 사용자 선택 반영 | 실제 A안 응답과 안내 한 문장·링크가 일치 | [논의·선택](execution.md#work-choose)과 실제 start.md |
| 원문·범위 밖 보존 | guide.md는 사례 원문과 같고 시작 안내 제목을 보존 | [전체 검수](execution.md#work-close)와 사례 원문 |

- 잔여: 이 시험용 부모의 잔여 없음. 실제 #72의 전체 완료·다른 사례의 실행은 별도다.
