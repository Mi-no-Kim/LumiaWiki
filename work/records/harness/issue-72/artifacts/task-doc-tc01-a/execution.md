## 원문 대조와 후보 작성

- 할 일: [원문 대조와 후보 작성](task.md#work-inspect)

- 조치·판단: r001과 준비된 두 시험 원문을 읽어 링크 표식의 불일치와 중복 문장 두 개를 확인했다. AI에 위임된 후보 작성 범위에서 설명 한 문장과 링크를 남기는 안과 링크만 남기는 안을 비교했다. 문서 수정이나 안내 방식 선정은 하지 않았다.
- 확인: start.md의 대상은 guide.md#record이고 실제 guide.md의 표식은 recording이다. “Task 본문은 현재 상태와 계획을 관리합니다.”와 “자세한 수행 내용은 별도 수행 기록에 남깁니다.”가 두 원문에 모두 있다. 두 후보는 guide.md#recording으로 연결하고 상세 두 문장을 그대로 반복하지 않는다. 두 입력 파일은 사례 원문과 같고 r001의 범위를 넘는 변경은 없다. 이 판정은 원문 대조·후보 준비에 한정하며 반영·사용자 선택·전체 완료를 확인한 결과가 아니다.
- 잔여: 없음 — 이 할 일의 원문 대조·후보 준비를 마쳤다. 사용자 선택은 다음 할 일에서 확인한다.

## 안내 방식 논의와 사용자 선택

- 할 일: [안내 방식 논의와 사용자 선택](task.md#work-choose)

- 조치·판단: 다음 두 안을 사용자에게 제시했다. 처음 읽는 사람에게는 A가 링크의 용도를 한 문장 더 알려 주고, B는 안내 분량이 가장 짧다는 이유로 A를 권고했다. 두 안은 상세 설명 원본을 guide.md에만 유지한다. 실제 사용자 응답 “A — 설명 한 문장과 링크 (추천)”을 확인해 A안을 선정했다. 질문이나 AI 권고를 선정 근거로 대신하지 않았다.

| 제안 | start.md에 남길 내용 | 연결 대상 |
|---|---|---|
| A — 설명과 링크 | “작업 상태와 상세 기록의 작성 방법을 확인하세요.” 한 문장과 “기록 방법 보기” 링크 | guide.md#recording |
| B — 링크만 | “기록 방법 보기” 링크 | guide.md#recording |

- 확인: 실제 선택 응답이 설명 한 문장과 링크를 남기는 A안을 지정했다. 선택이 맡겨진 주체·대상과 맞으며 이 할 일의 논의·결정 조건을 충족한다. 반영 전에 Task의 현재 합의·남은 결정·다음 행동·막힌 조건을 맞췄다. 이 할 일까지 입력 파일은 수정하지 않았다.
- 잔여: 없음 — 선택 결과의 반영·확인은 다음 할 일에서 한다.

## 선택한 안내 반영과 확인

- 할 일: [선택한 안내 반영과 확인](task.md#work-apply)

- 조치·판단: 실제 사용자 A안 선택과 r001의 반영 허용·선행 결과를 확인하고 start.md만 수정했다. 안내 한 문장과 올바른 링크를 남기고 상세 두 문장의 중복을 제거했다.
- 확인: 다음 네 조건을 수정한 실제 파일과 원문·응답에 대조해 충족으로 판정했다. guide.md는 입력 원문과 같고 start.md의 제목을 보존했다. 이 시험 입력 밖의 제품 문서는 수정하지 않았다. Task 전체 기록·종료는 다음 할 일에서 확인한다.

| 완료 조건 | 실제 관찰·근거 | 판정 |
|---|---|---|
| 링크 연결 | start.md의 대상 guide.md#recording과 실제 guide.md의 recording 표식이 일치 | 충족 |
| 상세 설명 중복 해소 | 원문의 두 상세 문장이 start.md에 남아 있지 않음 | 충족 |
| 사용자 선택과 반영 일치 | 실제 응답이 A안을 지정했고 수정본은 안내 한 문장과 링크를 포함 | 충족 |
| 원문·범위 밖 보존 | guide.md가 사례 원문과 같고 start.md 제목을 유지 | 충족 |

- 잔여: 없음 — 이 할 일의 반영·네 조건 확인을 마쳤다.

<a id="work-close"></a>
## 전체 결과 검수와 종료

- 할 일: [전체 결과 검수와 종료](task.md#work-close)

- 조치·판단: 수정 결과·실제 사용자 선택·r001을 기준으로 전체 수용·필수 종료 조건을 대조했다. 네 결과 조건을 충족하고 실제 할 일의 수행·확인·기록을 갖춰 Task를 완료로 판단했다. 이 판단을 부모의 자동 수용으로 확대하지 않았다.
- 확인: 시험 묶음 여섯 파일과 사례 정의의 로컬 참조가 유효했다. Task 주석 여덟 개와 수행 기록 주석 한 개가 각각 생성 원천과 같고 머리말 주석은 첫 작업 구역 앞에 한 번만 있다. 네 할 일·기록 구역이 왕복 연결되며 입력 원문 guide.md를 보존했다. 기록 규칙 위반은 없다. 수행 기록은 최초 착수 때 한 번 만들었고 후속 작업은 주석 없는 구역으로 추가했다. 별도 임시 파일·외부 반영·커밋은 없으며 필요한 결과·근거는 이 묶음에 보존한다. 같은 AI의 같은 문맥에서 기대 결과를 알고 수행한 사용 확인이므로 새 문맥·맹검·자동 운영의 독립 검증이나 다른 사례의 성공은 확인하지 않았다.
- 잔여: Task 자기 범위의 잔여 없음. 부모 전체 수용은 별도 결과 대조로 연결한다.
