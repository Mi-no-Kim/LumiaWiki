# 시험용 Task T 전달사항

- 태그: 조사, 논의, 결정, 실행, 검수

<a id="purpose"></a>
## 목적

시작 안내에서 기록 방법으로 정확히 이동하고, 같은 상세 설명을 두 문서에서 관리하는 문제를 줄인다.

<a id="result"></a>
## 기대 결과

수정한 시험용 start.md, 선택 이유와 완료 조건별 확인 결과.

<a id="scope"></a>
## 이미 정해진 조건

- 조건: guide.md를 상세 설명의 원본으로 유지하고, 두 문서를 읽되 start.md만 수정한다.
  - 적용 범위: 이 폴더의 시험 입력 두 파일.
  - 확정 근거: [부모의 배정 기준 기록](parent.md#assignment).
- 조건: 문안 선택은 사용자에게 맡기고 선택 뒤 반영한다. AI는 원문 대조·후보 작성·합의 안의 문안 정리와 검증 방법을 맡는다.
  - 적용 범위: 비교·선택·수정·확인.
  - 확정 근거: [부모의 배정 기준 기록](parent.md#assignment).
- 조건: 외부 등록·제품 파일 변경·커밋은 이번 시험에 포함하지 않는다.
  - 적용 범위: 시험 전체.
  - 확정 근거: [시험 설정](parent.md#setup).

<a id="decisions"></a>
## Task에서 결정할 사항

- 결정할 사항: 짧은 설명과 링크를 남길지, 링크만 남길지.
  - 결정 범위: start.md의 안내 방식.
  - 판단 기준: 상세 설명을 중복하지 않고 기록 방법을 찾을 수 있어야 한다.
  - 결정 주체: 후보를 비교한 뒤 실제 사용자가 선택한다. AI의 추천은 선택을 대신하지 않는다.

<a id="acceptance"></a>
## 완료 조건과 확인 방법

- 완료 조건: 링크가 실제 파일·표식으로 연결된다.
  - 확인 방법: start.md의 링크 경로와 guide.md의 실제 표식을 대조한다.
- 완료 조건: 두 상세 문장을 시작 안내에 그대로 중복하지 않는다.
  - 확인 방법: 원문 두 문장과 수정본을 대조한다. 설명과 링크 안은 짧은 별도 안내 한 문장, 링크만 안은 링크만 남긴다.
- 완료 조건: 사용자 선택과 수정본이 일치한다.
  - 확인 방법: 실제 선택 응답과 반영 문안을 대조한다. 응답 전에는 이 조건을 충족으로 판단하지 않는다.
- 완료 조건: guide.md 원문과 수정 범위 밖 내용을 보존한다.
  - 확인 방법: 사례에 제공한 원문과 실제 파일을 대조한다.
