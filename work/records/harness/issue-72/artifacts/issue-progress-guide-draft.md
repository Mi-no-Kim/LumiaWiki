# 이전 진행 기록 지시서의 연결 안내

작성안의 진행 기록 규칙은 [본문 양식의 규칙 주석](issue-body-template-draft.md#recording-guide)으로 통합했다. 현재 작업은 [파일 생성 지시서](issue-file-creation-guide-draft.md)와 본문 양식, [공통 절차](issue-common-procedure-draft.md)를 사용한다.

이 파일은 이전 링크를 유지하는 안내이며 별도의 작성·진행 규칙을 두지 않는다. 기존 구역의 현재 안내는 아래 본문 양식 링크에서 확인한다.
