## 주요 논의와 판정 근거

### 2026-11-07 — 문서 분할의 별도 제출

- 사용자는 이름 변경과 문서 분할 두 작업을 진행하되 추가 요청 판단 규칙은 하네스 skill 작업으로 남기도록 지시했다.
- 이후 허용 범위를 PR 생성까지 확대했고 병합은 명시적으로 금지했다.
- 독립 Issue를 다른 Issue에서 분기하는 새 경로를 만들지 않는다. 두 PR은 각각 main 기준이며 이름 변경을 먼저 반영한 뒤 분할을 갱신·병합하는 순서를 표시한다.
- 기존 기록과 AGENTS 진입 연결은 유지한다. 문서 정리를 별도 커밋 단계로 요구하거나 절차·양식을 추가 분할하지 않는다.
