# Task 81-002 확정 전달사항 r003

- 태그: 조사, 논의, 결정, 실행, 검수

<a id="purpose"></a>

## 목적

저장소 브랜치 이름 규칙을 로컬 생성·이름 변경과 원격 전송에 적용하고 초기화 전 로컬 백업을 보존한다.

<a id="result"></a>

## 기대 결과

브랜치 검사 훅을 구현하고 격리 저장소에서 검증한다. 승인된 실제 복제본에 두 훅을 설치하고 동작을 확인한 후 Task를 완료한다.

<a id="scope"></a>

## 이미 정해진 조건

- [r002의 이름·보존·격리 검증 조건](task-002-assignment-r002.md#scope)을 적용한다. 이름 변경·복사는 새 이름을 먼저 검사하는 `rename`·`copy` 명령을 사용한다.
- 실제 적용 대상은 이 프로젝트의 로컬 복제본이다. 공용 훅 경로와 연결 워크트리, 적용·복구 방법을 확인한 뒤 승인된 범위에서 설치한다.
- 실제 설치와 동작 확인을 Task 수용 조건으로 삼는다. 완료 근거를 확보한 뒤 Task 완료와 부모 PR 제출을 처리한다.
- 확정 근거: [실제 적용 완료 조건 합의](../issue.md#branch-hook-assignment-r003).

<a id="decisions"></a>

## Task에서 결정할 사항

승인받을 실제 훅 설치 경로와 실행 시점, 설치본의 검사 방법, 실패 시 복구 방법을 정리한다.

<a id="acceptance"></a>

## 완료 조건과 확인 방법

- [r002의 구현·격리 검증 조건](task-002-assignment-r002.md#acceptance)을 충족한다.
- 승인된 실제 복제본에 두 훅이 설치돼 있고 실제 훅 경로의 허용·거부 결과를 확인했다. 설치 전후에 기존 훅과 로컬 백업 참조를 대조하고 확인 범위와 한계를 수행 기록에 남긴다.
