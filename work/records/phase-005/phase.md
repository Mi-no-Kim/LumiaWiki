<a id="goal"></a>

## 목표와 범위 및 수용 조건

아래는 해당 단계의 범위와 검토용 수용 조건이다. 합의된 제품 요구를 기준으로 진입 또는 관련 Issue 착수 전에 세부 수용 기준을 확정한다.

**공동 목표/기대 결과**

앞선 단계의 기능을 합의한 전체 범위로 완성하고, 공개 서비스에 필요한 편의성·가시성·비주얼을 갖춘다.

**포함 범위**

- 검색·필터·미리보기·개별 페이지와 제작 관계 탐색을 완성한다.
- 버전 선택, 현재 없는 아이템의 별도 표시, 패치 이력·요약의 사용 경험을 정비한다.
- 장비 조합·후보 풀·스탯 조건·부위별 선택 방식 혼합 등 합의한 루트 탐색 기능을 완성한다.
- 결과 표시·정렬과 전체적인 조작 흐름을 다듬는다.
- P2에서 만든 개별 페이지 등 공개 대상 화면도 완성 범위에 포함한다.
- **최적화 수행 여부는 미정으로 유지한다.**

**완료 조건 — 검토 기준**

- 이 단계의 합의된 기능 목록과 실제 동작을 대조해 충족을 확인한다.
- 확정한 편의성·가시성·비주얼 기준을 충족한다.
- 기본 자료 조회부터 제작·이력·루트 탐색까지 필요한 흐름이 연결된다.
- 미정·향후 기능과 남은 문제가 구분돼 있다.
- 최적화를 채택했다면 확정한 대상과 목표에 따라 별도로 확인한다.

<a id="entry-decisions"></a>

### Phase 진입 또는 Issue에서 정할 사항

- 이 단계에서 완성할 기능·화면의 구체 목록과 품질 기준.
- 상세 검색·필터·버전 선택·제작 관계·결과 표시의 동작과 디자인.
- 장비 조합·루트 탐색의 알고리즘과 정렬·조건 충돌 처리.
- 수식 처리 기반을 다른 기능에 연결할 범위.
- 최적화의 필요성·수행 여부·대상·목표.

<a id="planned-checks"></a>

### 예정 확인

합의 기능의 동작과 사용성·비주얼 기준을 대조한다. 최적화를 채택한 경우에만 정한 목표의 확인을 추가한다.

실제 검증 결과는 수행한 때 기록한다. 현재는 계획만 등록한 상태다.

<a id="activity"></a>

## 주요 논의와 판정 근거

아래는 계획 등록 당시 근거다. 이후 계획 변경과 실제 수행은 후속 기록으로 구별한다.

<a id="registration"></a>

### 2026-10-30 검수한 구상 수정안의 정식 계획 등록

사용자의 이관 지시에 따라 검수한 수정안의 목표·범위·검토용 완료 조건·진입/Issue 결정 사항을 이 문서에 등록했다. 미정·후속·제안은 유지했으며 등록을 Phase 착수·완료로 판정하지 않았다. 공통 도입 순서와 반영 이유는 [제품 범위 이력](<../../../docs/history/제품 범위.md#seven-phase-formalization>)에서 확인한다.

<a id="role-separation"></a>

### 2026-11-05 제품 요구와 단계 계획의 역할 정리

사용자의 전체 반영 지시에 따라 단계 경계와 제품 요구·다른 단계의 참조를 정리했다. 포함 범위·검토용 수용 조건과 예정 상태를 유지했으며 기능 구현·Phase 완료를 판정하지 않았다.

<a id="result"></a>

## 결과와 미해결

계획 등록을 마쳤으며 Phase 목표의 실행 결과나 완료 판정은 아직 없다. 남은 결정은 [진입/Issue 결정 사항](#entry-decisions)에서 관리한다.
