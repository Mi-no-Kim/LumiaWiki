# 프로젝트 목표와 범위

<a id="current"></a>
## 제품 목표

루미아 아일랜드 위키는 게임 대상의 현재·과거 정보를 확인하고 패치의 변화를 이해하며, 아이템 제작·수집과 성능을 게임 밖에서 계산할 수 있게 한다.

<a id="scope"></a>
## 제공 범위

| 기능 | 사용자가 할 수 있어야 하는 일 | 상세 요구 |
|---|---|---|
| 게임 정보 탐색 | 아이템 등의 정보를 찾고 개별 정보·조합법을 확인한다. 캐릭터·특성도 다루며 기타 대상과 정보 범위는 구체화가 필요하다. | [아이템 탐색과 상세](<details/product/아이템 탐색과 상세.md#current>) |
| 당시 상태·패치 이력 조회 | 대상과 버전에 맞는 당시 정보를 확인하고 변경 이력을 살핀다. | [패치 이력과 요약](<details/product/패치 이력과 요약.md#versioned-history>) |
| 개별 패치 요약 | 한 패치에서 무엇이 바뀌었는지 대상 종류별로 파악한다. | [패치 요약](<details/product/패치 이력과 요약.md#patch-summary>) |
| 루트 계산 | 장비 구성과 조건에 맞는 제작·재료 수집·배달 조합을 찾는다. | [루트 계산기](<details/product/루트 계산기.md#current>) |
| 딜량 계산 | 게임 실행 없이 피해량을 계산하고 미반영 변경 조건의 성능 변화를 예측한다. | [딜량 계산기](<details/product/딜량 계산기.md#current>) |
| AI 패치노트 변환 | 패치노트 원문을 해석·구조화해 서비스 데이터로 변환하고 운영에 활용한다. | [게임 데이터 변경 관리](<details/product/게임 데이터 변경 관리.md#ai-transition>) |

<a id="quality"></a>
## 핵심 품질

- 아이템 탐색에서는 후발 서비스로서 편의성·가시성·비주얼을 중시한다. 특히 필터 설정과 적용 상태를 쉽게 파악할 수 있어야 한다.
- 과거 조회에서는 당시 정보의 버전 일치와 보존을 지킨다.

<a id="delivery"></a>
## 초기 공개 조건

- 딜량 계산기를 제외한 합의된 기능을 구현한다. 정보 탐색, 대상별 패치 이력 조회, 개별 패치 요약, 루트 계산과 AI 패치노트 변환이 포함된다.
- 시즌1·버전1.0.0부터 공개 시점 최신 패치까지 아이템 정보와 변경 이력을 모두 조회할 수 있어야 한다.
- AI 변환 결과를 관리자가 확인·수정한 뒤 공개 적용하는 운영 흐름을 갖춘다. 이후 AI 담당 범위의 확대는 [데이터 운영 요구](<details/product/게임 데이터 변경 관리.md#ai-transition>)를 따른다.

아이템 외 대상의 과거 제공 기간과 구체적인 기능·자료 완성 판정 기준은 미정이다. 범위를 추가·변경하면 공개 조건에 미치는 영향도 함께 판단한다.

<a id="limits"></a>
## 이용과 지원 경계

- 일반 이용자는 공개 조회·계산을 로그인 없이 사용한다. 수동 입력·정정·적용·되돌리기는 지정 관리자만 실행한다.
- 모바일 지원은 현재 요구에 포함하지 않는다. 영구 제외로 정한 것은 아니다.

<a id="damage-calculator"></a>
## 기능별 요구와 실행 계획

딜량 계산기의 입력·지원 범위는 [상세 요구](<details/product/딜량 계산기.md#current>)에서 정한다. 기능별 조건은 위 상세 문서가, 구현 순서·단계별 결과·의존 관계는 [Phase 계획 조회](<../work/현황.md#harness-record-separation>)이 담당한다. 문서 역할의 기준은 [제품 요구와 실행 계획의 관계](<문서 관리 기준.md#product-and-plan>)를 따른다.
