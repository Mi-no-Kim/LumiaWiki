# 루트 계산기

<a id="current"></a>
## 현재 결론

루트 계산을 주요 기능으로 다루며 계산에 필요한 입력/허용 조건과 결과, 계산용 가공 데이터의 범위를 제품의 공통 원자료/과거 기록과 구별한다. 구체 탐색·최적화 알고리즘과 저장·캐시 기술은 미정이다.

아이템 목록/개별 페이지의 탐색과 표시 요구는 [아이템 탐색과 상세](<아이템 탐색과 상세.md#current>)가 소유한다. 이 문서는 계산을 위한 장비 탐색·입력/조건과 결과를 소유한다.

<a id="equipment"></a>
## 장비 구성과 계산 대상

장비 구성은 [아이템의 5개 장비 부위](<아이템 탐색과 상세.md#item-information>)를 따른다. 일부 캐릭터는 특정 부위 장비가 고정되며 조합법 없이 스킬 레벨에 따라 등급이 올라간다. 전체 장비 부위가4개인 것이 아니라 루트에서 조합 제작할 대상이 4개다. 해당 캐릭터·장비/스킬 레벨별 자료와 세부 예외는 아직 제공되지 않았다.

전체 장비 구성과 일부 부위만 완성하는 계산을 모두 지원한다. 캐릭터 선택, 캐릭터 대신 무기군 선택, 캐릭터/무기군 지정 없이 아이템만 지정하는 계산을 지원한다. 캐릭터 선택을 모든 계산의 선행 조건으로 강제하지 않는다. 이는 아이템 관련 계산의 기존 입력 요구이며 캐릭터 전체 조회/사양을 추가로 확정하는 것은 아니다.

<a id="selection"></a>
## 아이템 선택 방식과 조합

- 특정 아이템을 직접 지정한다.
- 후보 아이템 풀에서 장비 조합을 찾는다. 후보 전부를 반드시 제작하는 뜻은 아니다.
- 스탯 조건으로 아이템을 탐색한다.

세 방식은 부위마다 섞어 사용할 수 있다. 사용자가 직접 지정한 제작 목표와 캐릭터의 전용 고정 장비를 구별한다. 구체 화면·선택 순서·기본값과 입력 조건 충돌, 캐릭터 미선택 시 고정 장비 예외 처리는 미정이다.

<a id="filters"></a>
## 계산용 스탯 필터

개별 아이템 기준과 장비 조합 전체 기준을 모두 지원한다. 개별 조건은 장비 부위마다 다르게 정할 수 있고 조합 전체의 합산 능력치 조건은 별도로 설정한다.

능력치마다 최소값·최대값 중 필요한 쪽을 입력할 수 있다. 최소만 입력하면 해당 값 이상, 최대만 입력하면 해당 값 이하, 둘 다 입력하면 그 범위의 값을 조건으로 삼는다. 여러 조건을 설정하면 설정한 모든 조건을 만족하는 결과만 표시한다. 기본값·모순된 범위 입력·조건 충돌과 화면의 세부 동작은 아직 정하지 않았다. 아이템 스킬의 효과를 수식으로 계산하는 결정은 아니다.

<a id="constraints"></a>
## 지역·배달의 허용 조건과 계산 경계

지역은 우선 방문 순서가 아닌 조합을 기준으로 다룬다. 같은 지역 집합의 나열 순서를 별도 결과로 나누지 않는다. 특정 지역에서 시작/종료하는 것은 후속 옵션 구상이며 현재 순서 계산의 필수 요구로 앞당기지 않는다.

방문 지역 수·배달 수의 허용 범위와 결과 정렬 기준은 사용자가 각각 선택할 수 있어야 한다. 사용자가 설명한 2루트 중심·3루트 이하/2배달 이하의 일반적 기준을 수정 불가능한 제한이나 확정 기본값으로 쓰지 않는다. 어떤 조건 조합을 항상 우선하는지도 정하지 않았다.

배달 비용은 루트 계산의 입력·탐색·허용 조건·최적화·정렬에서 제외한다. 비용 데이터는 [아이템의 배달 가격 표시](<아이템 탐색과 상세.md#acquisition-display>) 등 다른 용도에 유지한다. 배달 자체와 배달 수를 제외하는 것은 아니다.

배달 횟수는 재료별 부족 수량을 배달 한 번에 받는 수량으로 나누어 올림한 뒤 합산한다. 부족하지 않은 재료에는 추가 배달이 필요하지 않다. 지역별 재료 출현 수량은 계산에 사용하지 않지만 어떤 지역에서 획득할 수 있는지는 사용한다. 출현 수량의 원자료를 삭제하거나 실제 게임에서 무제한 획득이 가능하다고 주장하는 뜻은 아니다.

조합하다 남은 재료를 이후 제작과 추가 수집/배달 필요량에 반영한다. 최초 보유 구성은 별개로 적용 버전에 따라 고정되고 실제 아이템을 참조한다. 시작 무기는 선택한 무기군의 시작 무기로 정해진다. 이를 매회 사용자가 임의 보유 수량을 입력하는 기능으로 확대하지 않는다. 실제 버전 경계/아이템 목록은 미제공이며 남은 재료 활용의 최적화 방법은 구현 이슈 또는 마일스톤에서 결정한다.

<a id="results"></a>
## 계산 결과와 정렬

- 장비 조합 전체의 기본 능력치 요약을 기본으로 표시하고 개별 아이템의 능력치 상세를 볼 수 있게 한다. 앞서 논의한 마우스 올림·클릭/터치의 상세 접근을 유지하되 모바일 전용 제품 지원으로 확대하지 않는다.
- 선택한 지역 조합에서 구할 재료와 필요 수량, 배달받을 재료와 필요 수량을 기본 결과에 포함한다.
- 지역 수가 적은 순, 배달 수가 적은 순, 사용자가 고른 장비 조합 스탯이 높은 순/낮은 순의 정렬을 우선 지원한다. 향후 정렬 확장을 영구 제한하는 목록은 아니다.
- 조건에 맞는 결과를 찾지 못하면 그 사실을 안내한다. 원인 분석·조건 완화 추천까지 자동으로 추가한 것은 아니다.

정확한 표시 필드·능력치 합산 규칙·지역별 수량 배분·기본/복합 정렬·동률 처리·추가 정렬 방식과 전체 결과 화면은 미정이다. 아이템 스킬의 계산 효과를 전체 능력치에 합산하기로 정하지 않았다.

<a id="data-boundary"></a>
## 원자료·과거 기록과 계산용 가공 데이터

루트용 가공/캐시는 현재 버전과 도입 예정 버전을 다루는 방향이며 과거 기록/당시 상태 조회의 보존 책임과 구별한다. 이를 물리 테이블 두 개로 확정하지 않는다. 공통 원자료의 변경/정정과 보존은 [게임 데이터 변경 관리](<게임 데이터 변경 관리.md#current>)가 담당한다.

자료의 조건/버전과 실제 관찰을 연결하고 가공 데이터가 있다는 이유로 원본/과거 보존의 충족을 주장하지 않는다. 과거 자료의 초기 준비가 과거 루트 계산용 캐시의 장기 보존/계산 지원을 뜻하지는 않는다.

<a id="pending"></a>
## 미정과 관련 계획

구체 알고리즘·남은 재료 활용의 최적화, 가공·캐시의 생성·갱신과 저장 기술, 입력 조건의 충돌·예외 처리, 능력치 합산·결과 표시·정렬의 세부는 구체화가 필요하다. 본문의 확정된 입력·필터·허용 조건과 결과 요구는 유지한다.

아이템 스킬의 계산 표현은 [공통 데이터 요구](<게임 데이터 변경 관리.md#item-skills>)와 [딜량 계산기](<딜량 계산기.md#current>)를 따른다. 이를 루트 필터·능력치 요약에 자동 반영하는 요구는 확정하지 않았다.

최소 작동 범위는 [P1](<../../../work/records/phase-001/phase.md#goal>), 합의된 루트 탐색 기능의 완성은 [P5](<../../../work/records/phase-005/phase.md#goal>) 계획에서 확인한다.
