# 딜량 계산기

<a id="current"></a>

## 목적과 입력

게임을 실행하지 않고 피해량을 계산하고, 아직 게임에 반영되지 않은 변경 조건으로 성능 변화를 예측할 수 있게 한다.

계산 입력은 아이템 성능, 캐릭터 스킬·스탯, 선택한 특성, 게임 시스템과 데미지 규칙이다. 확보한 실제 게임 자료·규칙에 근거해 지원 범위를 정한다.

<a id="requirements"></a>

## 계산과 결과의 요구

- 계산에 쓰는 자료·규칙·수식의 버전을 일치시킨다.
- 계산 과정과 결과를 확인하고 근거와 대조할 수 있게 한다.
- 지원·미지원·미확정 규칙을 구별한다.
- 공개용 기능에서는 사용자가 입력·결과·지원 범위를 이해하고 이용할 수 있게 한다.

아이템 스킬의 설명·공유 정의와 계산 표현의 경계는 [게임 데이터 변경 관리](<게임 데이터 변경 관리.md#item-skills>)를 따른다. 계산 효과를 루트 계산의 기본 능력치 요약이나 필터에 자동 합산하는 요구는 확정하지 않았다.

<a id="pending"></a>

## 미정

수식의 역할·표현·저장·버전 보존·사용자 로컬 수정 등에 관한 구체 논의는 사용자 지시에 따라 딜량 계산기 작업 때 진행한다. 그 전의 아이템 등록·표시나 P1 범위 결정의 선행 조건으로 삼지 않는다.

단발 피해·지속 피해·DPS의 지원 여부와 범위, 공격·방어·발동·지속·중첩 조건, 공식·수식 표현, 지원 버전과 미반영 변경 조건 지정 방식, 결과 검증 기준과 사용자 화면은 구체화가 필요하다.

초기 공개의 필수 완료 기능에서는 제외하며 [프로젝트 공개 조건](<../../프로젝트 목표와 범위.md#delivery>)을 따른다. 내부 기반과 공개용 완성의 단계 배치는 [계산 기반 계획](../../../work/records/phase-003/phase.md#goal)과 [공개용 완성 계획](../../../work/records/phase-007/phase.md#goal)에서 확인한다.
