# 게임 데이터 변경 관리

<a id="current"></a>
## 현재 결론

게임에서 실제로 바뀐 내용과 입력 오류의 정정을 구별하고 과거 기록/당시 상태를 보존한다. 수동 적용/되돌리기는 개별 변경 항목과 관련 영향을 기준으로 다룬다. 저장 구조·연결/복구 수단과 구체 운영 구현은 아직 정하지 않았다.

<a id="change-and-correction"></a>
## 변경·정정과 관련 영향

조회 정보의 버전을 일치시키고 현재 원본·과거 기록·목적별 가공 데이터를 구별한다. 과거의 유효한 근거를 현재 값으로 덮거나 특정 버전의 입력 오류 정정을 새로운 실제 게임 패치로 꾸미지 않는다.

특정 패치의 일부를 수동 적용/되돌리는 기능을 포함하며 속성별 개별 변경 항목을 선택 단위로 삼는다. 동일 아이템의 여러 속성이 한 패치에서 함께 바뀌어도 각 속성의 변경을 따로 선택하여 적용하거나 되돌릴 수 있어야 한다. 선택한 항목에 연결돼 영향을 받는 모든 부분을 함께 조사/반영한다. 기능 확장에 따라 대상도 늘어나므로 완결된 영향 목록을 지금 고정하지 않는다. 사용자가 언급한 linked list는 연결 구상이며 물리 자료구조·갱신 알고리즘이나 Spring 채택을 확정한 것이 아니다.

정정 저장/이력 방식·여러 항목의 묶음 처리·관련 대상의 구체 연결/복구와 화면은 미정이다. 실제 반영/미반영·검증/미확인·잔여는 [work](<../../../work/README.md#start>)의 담당 기록에서 확인한다. 실제 원자료/스키마가 주어지면 담당 원본을 참조하고 같은 사본을 독립 관리하지 않는다.

<a id="permissions"></a>
## 사용자 역할과 권한

수동 입력·정정·적용·되돌리기는 지정 관리자만 실행하고 일반 이용자는 공개된 조회·계산을 로그인 없이 사용한다. 관리자 계정/지정·인증 방식·세부 권한과 추가 계정 기능은 아직 정하지 않았다.

제품의 AI 변환·검토·공개 적용은 [단계적 전환](<#ai-transition>) 방향을 따른다. 도입 예정·비공개/미검증 자료의 구체 공개 시점과 세부 관리 권한은 후속 설계 대상이다.

<a id="ai-transition"></a>
## AI 변환의 입·출력과 단계적 전환

새로 게시된 패치노트 원문을 입력으로 받아 AI가 내용을 해석·구조화하고, 우리 서비스의 데이터로 자동 변환한다. 출력은 서비스에서 사용할 변환 자료이며, 아래 단계별 검토·공개 적용 흐름에 연결한다.

게시 감지·수집 방식, 변환 산출물의 구체 형식·저장/연결과 검증 절차는 후속 설계에서 정한다.

AI 변환 기능을 도입한 뒤에는 관리자 확인을 거치는 운영부터 시작해 AI가 맡는 범위를 점진적으로 넓힌다.

- 초반에는 AI가 패치노트의 아이템 변경 내용을 변환하고, 관리자가 내용을 확인·수정한 뒤 공개 적용한다.
- 이후에는 AI가 맡는 범위를 점차 넓힌다. 중간 단계를 몇 개로 나눌지와 각 단계의 구체 범위는 아직 정하지 않았다.
- 최종 목표는 AI가 변환 이후의 확인·수정·공개 적용 흐름까지 맡는 것이다.

초기 공개는 [프로젝트 공개 조건](<../../프로젝트 목표와 범위.md#delivery>)에 정한 AI 변환·관리자 확인/수정·공개 적용 단계에서 진행한다. 이후 단계별 AI 담당 확대의 전환 조건/시점·구체 검증 방법·오류/예외 처리와 관리자 개입 방식은 후속 설계에서 정한다. 초기 공개의 다른 기능·자료 조건도 해당 프로젝트 범위를 따른다.

<a id="item-skills"></a>
## 아이템 스킬의 현재 해석 범위

아이템 스킬은 현재 설명 텍스트로 관리한다. 여러 아이템이 스킬 정의를 공유하면서 적용 수치/계수가 다를 수 있고 한 스킬에 여러 작용이 포함될 수 있다는 도메인 설명을 유지한다. 이를 저장/해석할 구체 형식, 연결·텍스트 이력과 세부 속성은 아직 정하지 않았다.

계산용 수식·실행 효과의 지원 범위·표현·규칙·검증은 미정이다. 계산 표현을 마련하더라도 원래 설명 텍스트와 기존 도메인 정보는 보존한다. 계산 기능의 요구는 [딜량 계산기](<딜량 계산기.md#current>)를 따른다. 설명 안의 수치를 계산 가능한 데이터로 취급하거나 조합식/스탯 필터용 기본 능력치까지 텍스트만으로 관리한다는 뜻은 아니다. 아이템 목록에서 스킬을 기준으로 필터하는 기능의 필요성은 [아이템 탐색](<아이템 탐색과 상세.md#search-and-filters>)에 기록하며 그 요구를 스킬 효과 수식화로 확대하지 않는다.

<a id="initial-data"></a>
## 자료의 대상과 기간

과거 자료는 정식 출시·시즌1·버전1.0.0을 시작 기준으로 한다. 아이템 정보·조합법·획득 지역을 다루며, 정보의 기본 틀은 [아이템의 다섯 정보 묶음](<아이템 탐색과 상세.md#item-information>)을 따른다. 초기 공개에 필요한 전체 기간은 [프로젝트 공개 조건](<../../프로젝트 목표와 범위.md#delivery>)을 따른다.

아이템 외 대상의 구체 목록·정보 항목·기준 버전·과거 제공 기간과 자료의 완성 판정·저장 방식은 미정이다. 사용자 자료의 확보·임시 변환·교정과 등록 순서는 [초기 자료 준비 계획](<../../../work/records/phase-001/phase.md#input-workflow>)에서 다룬다.

<a id="boundaries"></a>
## 관련 요구와 계획

루트 계산용 자료는 [루트 계산기](<루트 계산기.md#data-boundary>), 버전별 조회는 [패치 이력과 요약](<패치 이력과 요약.md#versioned-history>), 아이템 탐색·표시는 [아이템 탐색과 상세](<아이템 탐색과 상세.md#current>)가 담당한다. 공통 변경·정정·보존과 AI 운영 요구는 이 문서가 담당한다.

실제 변경 처리의 검증은 [P4](<../../../work/records/phase-004/phase.md#goal>), AI 변환의 초기 도입은 [P6](<../../../work/records/phase-006/phase.md#goal>) 계획에서 확인한다. 단계별 배치와 실행 상태를 이 문서에서 별도로 관리하지 않는다.
