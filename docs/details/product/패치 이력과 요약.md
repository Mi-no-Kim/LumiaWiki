# 패치 이력과 요약

<a id="current"></a>

## 현재 결론

대상별 패치 이력 조회와 개별 패치 요약을 주요 기능으로 다룬다. 대상의 당시 상태·변경 흐름과 한 패치의 변경 내용을 각각 확인할 수 있어야 한다. 아이템 외 대상의 최종 목록·정보 범위는 미정이다.

<a id="versioned-history"></a>

## 조회 목적과 버전 경계

대상/버전을 선택해 당시 상태를 확인하는 조회에 더 높은 비중을 두고 변경 이력 조회도 유지한다. 이름·등급·능력치·아이템 스킬 설명·조합법 등 함께 표시하는 정보의 버전을 일치시킨다. 현재 값으로 과거를 덮거나 서로 다른 버전 정보를 섞지 않는다. 실제 스냅샷·변경분·재구성/저장 방식은 후속 결정이다. 공통 보존/정정은 [게임 데이터 변경 관리](<게임 데이터 변경 관리.md#current>)를 따른다. 이 원칙 자체가 아이템 목록의 과거 버전 필터 도입을 뜻하지 않으며, 목록과 개별 페이지의 실제 선택 범위는 [아이템의 화면별 버전 선택](<아이템 탐색과 상세.md#version-selection>)을 따른다.

종류의 이름·상하위 관계는 [분류 기준](<아이템 탐색과 상세.md#classification>)에 따라 버전 없이 현재 기준을 사용한다. 과거 아이템 조회도 이 예외를 적용하며 아이템 자체의 소속 종류 ID 변경 이력은 유지한다.

임의의 두 버전을 골라 대상의 상태를 직접 비교하는 추가 기능은 현재 범위에 포함하지 않는다. 당시 상태·변경 이력 조회를 철회하는 것은 아니며 영구 금지도 아니다. 아이템 개별 페이지의 역대 이력과 최신 메이저 패치부터 비교하는 표현 구상은 [아이템 페이지의 담당 구역](<아이템 탐색과 상세.md#patch-history>)에서 확정/미정을 구분한다.

<a id="patch-summary"></a>

## 개별 패치 요약

개별 패치에서 무엇이 바뀌었는지 파악하도록 대상 종류별로 묶고 변경된 대상과 내용을 보여준다. 대상 종류의 최종 목록과 구체 분류 체계는 아직 정하지 않았다.

변경 내용의 구체 표현은 미정이다. 수치 전/후 표시·문장 요약·버프/너프 판정 등을 일괄 채택하지 않는다. 아이템 페이지의 비교 표현 구상을 모든 패치 요약의 확정 방식으로 확대하지 않는다.

<a id="pending"></a>

## 미정과 관련 계획

실제 게임 자료·버전별 내용, 저장·조회 구조, 패치 요약의 상세 표현과 추가 검색·탐색 동작은 구체화가 필요하다. 이미 합의한 [아이템 검색·필터](<아이템 탐색과 상세.md#search-and-filters>)는 유지한다.

실제 패치로 저장·조회·표현을 보완하는 단계는 [P4](../../../work/records/phase-004/phase.md#goal), 합의한 기능·화면의 완성은 [P5](../../../work/records/phase-005/phase.md#goal) 계획에서 확인한다. 자료 제공 기간과 공개 조건은 [프로젝트 목표와 범위](<../../프로젝트 목표와 범위.md#delivery>)를 따른다.
