# 권한과 실행 범위

## 현재 결론

요청에서 허용한 결과·대상·행동 범위 안에서 수행한다. 조회·계획·리뷰 요청을 수정·구현·외부 행동으로 확대하지 않는다. 이미 허용된 행동은 반복 승인받지 않는다.

기존 허용을 벗어나는 새 선택이나 범위 변경이 필요하면, 달라지는 내용과 영향·선택안을 제시한다. 관리자 역할이나 도구 접근 가능성만으로 실행 권한이 확대되지는 않는다.

현재 대상·입력·사용자 변경·허용 범위·수용 조건을 확인한다. 사용자 요구와 AI 제안, 합의와 실제 반영, 예정과 관찰, 추론과 과거 근거를 구별한다.

원천·입력·권한·기준이 부족하거나 충돌하면 의존하는 행동과 완료 판정을 제한하고 필요한 확인을 반환한다. 독립적으로 허용된 작업은 계속한다.

## 관련 기준

실제 확인과 완료 판정은 [검증과 완료](<검증과 완료.md>), 다른 운영 기준의 선택은 [운영 기준 안내](<../../하네스 운영 기준.md>)에서 확인한다.
