# 별도 검수

## 현재 결론

자체 대조를 기본으로 하며, 다음 경우에는 별도 검토자를 연결한다.

- 사용자·수용 조건·적용 지침이 별도 검수를 요구한 경우
- 원천의 소유·등록 책임, 권한, 상태·종료·검증의 의미와 조건, 공용 절차의 책임 등 운영 규칙 자체를 새로 정하거나 변경하는 경우
- 보존 원본을 이전·삭제하거나, 광범위한 참조 변경으로 유일한 근거를 잃을 수 있는 경우

기존 기준에 따른 등록·현황 갱신·같은 의미의 표현 보완은 그 자체만으로 별도 검수 대상이 되지 않는다. 파일 수만으로 검수를 강제하지 않는다.

검토자는 필요한 원자료와 현재 대상을 확인한다. 작성자는 지적을 근거와 대조해 반영하고 관련 부분을 재확인한다. 충돌은 근거로 해소하거나 미확인으로 남기며, 다수의 동의만으로 통과시키지 않는다.

실제 검토 범위와 한계를 밝힌다. 같은 모델의 역할·문맥 분리를 다른 모델의 검증이나 맹검 검증으로 보고하지 않는다.

## 관련 기준

검수의 실제 확인과 완료 판정에는 [검증과 완료](<검증과 완료.md>)를 적용한다. 다른 기준의 선택은 [운영 기준 안내](<../../하네스 운영 기준.md>)에서 확인한다.
