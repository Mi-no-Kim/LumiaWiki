# 관찰과 개선

## 현재 결론

실패·의미 있는 정상 사용·사용자 피드백을 담당 기록에 남기고, 근거가 뒷받침하는 원인과 추정을 구별한다.

요구의 부재, 지침 불이행, 절차·도구 문제, 관찰의 누락을 구분해 필요한 최소 변경을 판단한다. 근거 없이 규칙을 늘리지 않으며, 변경하지 않거나 불필요한 안내·절차를 줄이는 선택도 검토한다.

개선 여부는 관련 문제의 재확인과 실제 후속 사용에서 나타난 효과·한계로 판단한다. 문구 보완이나 구조 검사만으로 운영 개선이 달성됐다고 보고하지 않는다.

## 관련 기준

변경의 허용 범위는 [권한과 실행 범위](<권한과 실행 범위.md>), 필요한 확인과 완료 판정은 [검증과 완료](<검증과 완료.md>)를 적용한다. 실제 수행 흐름은 [공용 절차의 사용 관찰과 개선](<../../../harness/공용 절차.md#feedback>), 다른 기준의 선택은 [운영 기준 안내](<../../하네스 운영 기준.md>)에서 확인한다.
